## Highlights

**Initial release** · v0.0.1

PlainPaste is a tray utility for macOS, Windows and Linux (X11). Press a global hotkey, and it pastes the clipboard as plain text. Linux needs the `libfontconfig1` package at run time.

### ✨ Added

- A tray icon with a menu: **Settings** and **Quit**. A left click on the icon opens the settings flyout.
- A global paste hotkey. The default is Ctrl+Shift+V on Windows and Linux, and Cmd+Shift+V on macOS.
- You can change the hotkey in Settings. If another app already uses the key combination, Settings shows a message and keeps the previous hotkey.
- Plain-text paste: on the hotkey, PlainPaste reads the clipboard as text and pastes it into the focused app.
- Setting **Keep line breaks**. It is off by default. When it is off, each run of line breaks becomes one space.
- Setting **Restore clipboard after paste**. It is on by default. PlainPaste puts back the original clipboard content with all its formats.
- Setting **Theme**: System, Light or Dark. The default is System.
- Native clipboard support on macOS, Windows and Linux (X11).

### 🛠 Fixed & Improved

- First release. No earlier version exists.

### ⚙️ Internal / Build

- Release assets: `plainpaste-0.0.1-macos-arm64.zip`, `plainpaste-0.0.1-windows-x86_64.exe` and `plainpaste-0.0.1-linux-x86_64`.
- The macOS app has an ad-hoc signature. It is not notarized.
- Linux supports X11 only. Under Wayland, global hotkeys and simulated input are restricted.
- The Windows build uses the GUI subsystem, so no console window opens.

## 版本重點

**首次釋出** · v0.0.1

PlainPaste 是適用於 macOS、Windows 與 Linux（X11）的系統匣小工具。按下全域快捷鍵，就會把剪貼簿內容以純文字貼上。Linux 執行時需要 `libfontconfig1` 套件。

### ✨ 新增

- 系統匣圖示與選單：**設定**與**結束**。左鍵點擊圖示會開啟設定面板。
- 全域貼上快捷鍵。預設在 Windows 與 Linux 為 Ctrl+Shift+V，在 macOS 為 Cmd+Shift+V。
- 可在設定中更改快捷鍵。若該組合鍵已被其他程式使用，設定會顯示提示並保留原本的快捷鍵。
- 純文字貼上：按下快捷鍵時，PlainPaste 以文字讀取剪貼簿，並貼到目前焦點的應用程式。
- 設定**保留換行**。預設為關閉。關閉時，連續的換行會合併為一個空格。
- 設定**貼上後還原剪貼簿**。預設為開啟。PlainPaste 會把原本剪貼簿的所有格式內容放回去。
- 設定**主題**：系統、淺色或深色。預設為系統。
- 支援 macOS、Windows 與 Linux（X11）的原生剪貼簿。

### 🛠 修正與改善

- 首次釋出，沒有更早的版本。

### ⚙️ 內部/建置

- 發行檔案：`plainpaste-0.0.1-macos-arm64.zip`、`plainpaste-0.0.1-windows-x86_64.exe` 與 `plainpaste-0.0.1-linux-x86_64`。
- macOS 應用程式使用 ad-hoc 簽章，未經公證。
- Linux 僅支援 X11。在 Wayland 下，全域快捷鍵與模擬輸入受限。
- Windows 版本使用 GUI 子系統，不會開啟主控台視窗。
