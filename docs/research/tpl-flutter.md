## Top picks for Android+macOS+Windows

1. **material_ui (+ cupertino_ui)** — official, decoupled from SDK since Aug 2026; Material 3 works identically on Android/macOS/Windows; one codebase, no per-platform divergence.
2. **very_good_cli** — org-maintained, daily activity, generates tested app skeleton (Bloc, l10n, CI) for all three targets.
3. **forui** or **shadcn_ui** — one custom design system across platforms (no per-platform widget forks); forui is org-backed, shadcn_ui has more contributors but single owner; both pre-1.0.
4. **flex_color_scheme + dynamic_color** — theming for Material 3; note flex_color_scheme is single-maintainer.
5. **window_manager** — maintained desktop window control for macOS/Windows; avoid flutter_adaptive_scaffold (discontinued) — write a small own breakpoint helper instead.

Caveats: if native-look per platform is required, macos_ui (slowing) + fluent_ui (active, single owner) mean divergent widget trees per platform, which conflicts with the no-fork policy — prefer a single design system (picks 1/3).
